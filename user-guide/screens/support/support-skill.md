# Support skills: qualified technician routing

<IerpPageSummary purpose="Catalog the technical skills used to qualify team members and support routing decisions." useWhen="Ticket assignment must distinguish general support from specialized calibration, installation or repair work." owner="Support and Maintenance" />

## When to use this page

Ticket assignment must distinguish general support from specialized calibration, installation or repair work.

## Typical tasks

- Follow the documented “Why skill catalog accuracy matters” instructions below.
- Follow the documented “Maintain the catalog” instructions below.

## Why skill catalog accuracy matters

Skills are an optional Smart Routing configuration workspace. A skill is not a certificate by itself: employee/team membership and the actual task's requirements still need verification. Never auto-assign an unqualified employee solely because a similarly named skill exists.

<IerpScreenshot id="support-support-skill-index" title="Support skills" description="Check active skills before using them in team membership or ticket routing." path="Advanced Support → Skills" />

## Maintain the catalog

<IerpScreenshot id="support-support-skill-create" title="Create a technical skill" description="Record a unique code and clear competency name before enabling it." path="Skills → Create" />

Use stable codes and specific names such as calibration, installation or a product-family diagnosis. Check duplicates and confirm the skill is actively supported by trained employees.

<IerpScreenshot id="support-support-skill-edit" title="Edit a skill" description="Change activation or description carefully because existing routing rules can require the competency." path="Skills → Edit" />

Disabling a skill can make future automatic matches impossible. Review active routing rules and team assignments first, then verify that unresolved cases still have qualified owners. Creating/editing a catalog entry does not change an existing ticket's status or warranty decision.
