Use this screen to review its available records and supported actions.

<IerpNavigationPath :items='["Employees","Planning","Sales Plans"]' />

Create one employee's monthly plan, objectives and tasks before measuring field performance. Planning changes are audited and distinct from task execution.

## Plan workflow

1. On the list, filter by **Status** and inspect employee, plan name, month and task count.
2. Create a plan by choosing the employee, target month, required visit minutes and assessment weights. Review the displayed total weight before saving.
3. Add and schedule plan tasks through the plan/task workflow. Task statuses are Pending, In Progress, Completed and Cancelled.
4. Review the plan's status and tasks in **View**. Move it through **Draft**, **Published**, **In Progress**, **Completed** or **Archived** with permitted actions; do not edit status values as a shortcut.
5. Use **Edit** only for eligible records and permissions. **Copy To Month** duplicates a plan into the requested period; verify the destination month and employee before using it.
6. Performance scoring distinguishes completed base tasks from generated follow-up tasks, so follow-ups must not inflate the base task completion denominator.
