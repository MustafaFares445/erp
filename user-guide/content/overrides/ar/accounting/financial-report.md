## متى تستخدم هذه الصفحة؟

مطابقة فترة أو تدقيق القيود أو إعداد القوائم المالية.

## المهام الشائعة

- راجع قسم «طريقة الاستخدام» واتبع التعليمات المحددة فيه.
- راجع قسم «عند وجود فرق» واتبع التعليمات المحددة فيه.

<IerpScreenshot id="accounting-financial-report-index" title="التقارير المالية" description="اختر نوع التقرير والفلاتر؛ عرض النتائج لا يغير القيود." imageSrc="/images/ar/accounting/accounting-financial-report-index.png" />

## طريقة الاستخدام

1. افتح **التقارير المالية** واختر **ميزان المراجعة** أو **دفتر الأستاذ** أو **الأرباح والخسائر** أو **الميزانية العمومية** أو **سجل الترحيل**.
2. اختر الفترة المالية أو تاريخ البداية والنهاية، وفي الميزانية العمومية حدد تاريخ **كما في**. يتيح دفتر الأستاذ تحديد حساب عند الحاجة.
3. راجع العملة وحدود التاريخ والأرصدة وقارن الإجماليات مع القيود الأصلية وسجل الضرائب.
4. استخدم التصدير المسموح إذا أردت ملفًا؛ لا يؤدي العرض أو التصدير إلى ترحيل قيد أو تصحيحه أو إقفال الفترة.

## عند وجود فرق

التقرير يعكس القيود المحفوظة ولا يصلحها تلقائيًا. تتبع الحركة إلى المستند الأصلي في المبيعات أو المشتريات أو المدفوعات أو المحاسبة، ثم استخدم مسار التصحيح أو العكس المعتمد. لا تغيّر أرقام التقرير مباشرة.
