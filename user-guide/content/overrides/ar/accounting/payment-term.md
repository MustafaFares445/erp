# شروط الدفع

<IerpPageSummary purpose="إدارة قواعد الاستحقاق القابلة لإعادة الاستخدام في مستندات العملاء والموردين." useWhen="ضبط مهلة السداد أو مراجعة موعد استحقاق مستند." owner="الإعدادات المشتركة" />

## متى تستخدم هذه الصفحة؟

ضبط مهلة السداد أو مراجعة موعد استحقاق مستند.

## المهام الشائعة

- راجع قسم «قائمة شروط الدفع» واتبع التعليمات المحددة فيه.
- راجع قسم «إضافة شرط دفع» واتبع التعليمات المحددة فيه.
- راجع قسم «تعديل شرط دفع» واتبع التعليمات المحددة فيه.

تحدد شروط الدفع طريقة احتساب الاستحقاق للمستندات الجديدة، لكنها ليست دفعة أو قيدًا محاسبيًا. راجع الفواتير المرتبطة قبل تعديل الشرط؛ لا ينبغي أن يؤدي تغيير قاعدة مشتركة إلى محو تواريخ الاستحقاق أو المدفوعات السابقة. يحتاج الإنشاء والتعديل إلى الصلاحيات المناسبة.
