# إعداد المخزون

## متى تستخدم هذه الصفحة؟

مراجعة السجلات المخزنية وتصفيتها وتنفيذ الإجراءات وفق المرحلة والصلاحية.

## المهام الشائعة

- راجع قسم «المهام المعتادة» واتبع التعليمات المحددة فيه.
- راجع قسم «قواعد العمل وحل المشاكل» واتبع التعليمات المحددة فيه.
- راجع قسم «مراجع الشاشات» واتبع التعليمات المحددة فيه.

## متى تستخدمها؟
أدر تعريفات أنواع التغليف وأبعادها لإجراءات التعبئة.

## المهام المعتادة
1. افتح مساحة العمل من تنقل المخزون وتحقق من اللغة والمستودع والسجل المحدد.
2. استخدم البحث وفلاتر الحالة أو التبويب المناسب للوصول إلى المستند الصحيح.
3. راجع الكميات والوحدات والمراجع المصدرية والمرحلة والإجراءات المسموحة قبل التعديل.
4. تأكد من حالة السجل الناتجة وراجع الحركات بعد أي ترحيل مادي مستقل ومصرح به.

## قواعد العمل وحل المشاكل
نوع الطرد بيانات مرجعية وليس طرداً مادياً أو حركة مخزون.

إن غاب إجراء فتحقق من الصلاحيات ومرحلة السجل. قد يكون الجدول الفارغ نتيجة تصفية أو عدم وجود بيانات تجريبية. فتح الرابط لا يثبت تنفيذ إجراء مخزني.
