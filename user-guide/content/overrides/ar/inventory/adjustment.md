# تسويات المخزون

<IerpPageSummary purpose="إجراء تسويات كمية المخزون المعتمدة مع الحفاظ على حركات قابلة للتدقيق." useWhen="إعداد مسودة التسوية وتعديل البنود وتأكيد الكميات." owner="Inventory" />

## متى تستخدم هذه الصفحة؟

إعداد مسودة التسوية وتعديل البنود وتأكيد الكميات.

## المهام الشائعة

- راجع قسم «متى تُستخدم؟» واتبع التعليمات المحددة فيه.
- راجع قسم «الإجراءات» واتبع التعليمات المحددة فيه.
- راجع قسم «التصحيح والحدود» واتبع التعليمات المحددة فيه.

## متى تُستخدم؟

تسوية المخزون هي مستند رقابي لتصحيح كمية متغير منتج ضمن مستودع وحالة مخزون وتشغيلة أو رقم تسلسلي محدد. استخدمها لمعالجة الفروقات الفعلية المبرّرة، ومنها فروقات الجرد المعتمدة. **حفظ المسودة أو تعديلها لا يرحّل أي حركة مخزون.**

## الإجراءات

1. افتح **المخزون ← العمليات ← التسويات** ثم **إضافة تسوية مخزون**.
2. اختر المستودع وتصنيف السبب، وأدخل شرحاً واضحاً يمكن مراجعته.
3. أضف البنود وحدّد المتغير وحالة المخزون والتشغيلة أو الرقم التسلسلي عند اللزوم. أدخل الكمية الجديدة وراجع الكمية الحالية والفرق المحسوب.
4. احفظ المسودة ثم راجع البنود. لا يمكن تحويل التسوية المؤكدة إلى سجل قابل للتعديل لاحقاً.
5. راجع أثر الترحيل وأكّد العملية فقط إذا كنت مخولاً. بعد التأكيد، تحقق من الرصيد النهائي والحركات الناتجة ومصدرها. لا يُقبل تغيير يخالف الرصيد المتاح أو قيود التتبّع.

## التصحيح والحدود

عند الحاجة استخدم إجراء **إنشاء تسوية عكسية** الصريح بدلاً من تعديل السجل المؤكد بصمت. إذا نشأت التسوية عن جرد فيجب الاحتفاظ بالربط بين المستندين. تسوية المخزون لا تُصدر فاتورة مورد أو إشعاراً دائناً أو استرداداً مالياً. استخدم البحث والفلاتر لمطابقة رقم المستند والمستودع والحالة والسبب.

راجع [الجرد](/ar/screens/inventory/inventory-count) و[حركات المخزون](/ar/screens/inventory/stock-movement).

## صفحة View: اعتماد التسوية والتشخيص

تعرض صفحة View قسم الحالة التشغيلية والإجراء التالي قبل تفاصيل التسوية. راجع المستودع والأصناف والكمية القديمة والجديدة والفرق. المسودة لا تغيّر المخزون؛ التأكيد يرحّل الحركة ويتطلب مستخدماً مخوّلاً غير منشئ المستند. عالج خطأ التسوية المرحّلة عبر تصحيح مرتبط لا بتغيير السجل الأصلي.
