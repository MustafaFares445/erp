# تغييرات حالة المخزون

## متى تستخدم هذه الصفحة؟

إعداد الحقول التابعة لنوع تغيير الحالة ومراجعة المستند المرحّل.

## المهام الشائعة

- راجع قسم «الهدف» واتبع التعليمات المحددة فيه.
- راجع قسم «إجراءات كل نوع» واتبع التعليمات المحددة فيه.
- راجع قسم «ضوابط وحالات خاصة» واتبع التعليمات المحددة فيه.

## الهدف

تُستخدم مستندات تغيير الحالة لتحويل المخزون بين **قابل للبيع** و**الحجر** و**التالف**، أو لإخراج الكمية نهائياً من عهدة المستودع. يدعم النموذج أربعة أنواع: **معالجة الحجر** و**التلف** و**الاستعادة من التلف** و**الإتلاف**. لكل نوع شروطه وحقوله التابعة؛ يجب أن تتغير الحقول الظاهرة عند اختيار النوع.

## إجراءات كل نوع

1. افتح **المخزون ← العمليات ← تغييرات حالة المخزون** ثم **إضافة تغيير حالة المخزون** واختر نوع المستند.
2. **معالجة الحجر:** حدّد المخزون المحجور والتشغيلة أو الرقم التسلسلي عند الحاجة، ثم اختر نتيجة الفحص: إعادة للمخزون القابل للبيع، تحويل لتالف، إتلاف أو إرجاع للمورد بحسب الخيارات المتاحة. أدخل الكمية والسبب.
3. **التلف:** حدّد متغير المنتج والمستودع وبيانات التتبع، ثم انقل الكمية المؤهلة فقط إلى حالة التالف مع توضيح السبب.
4. **الاستعادة من التلف:** حدّد مستند التلف الأصلي والكمية المؤهلة للاستعادة. يحدد المستند المرجعي هوية المنتج والمستودع؛ لا تُدخل هوية مختلفة عن المصدر.
5. **الإتلاف:** اختر المخزون المؤهل للإخراج النهائي والكميات والسبب والتفويض المطلوب. راجع الأثر غير القابل للتراجع مباشرة قبل الترحيل.
6. راجع المسودة ثم رحّل أو ألغِ فقط بحسب الحالة والصلاحية. طابق أرصدة حالات المخزون والحركات المرتبطة بالمستند.

## ضوابط وحالات خاصة

تحقق من السبب والكمية وقرار الفحص ومرجع مستند التلف والشخص المفوّض عندما تظهر هذه الحقول. يُرفض أي تركيب غير صالح أو بيانات إلزامية ناقصة. يتغير الرصيد المتاح أو الفعلي بحسب نوع الحركة، لكن لا تنشأ إشعارات دائنة أو استردادات مالية تلقائياً. لا تعدّل المستند المرحّل بصمت.

راجع [أرصدة المخزون](/ar/screens/inventory/stock-level) و[حركات المخزون](/ar/screens/inventory/stock-movement).

## صفحة View: حالة البضاعة والقرار

يشرح قسم الحالة التشغيلية والإجراء التالي وضع مستند تغيير الحالة. راجع نوع الإجراء (معالجة الحجر أو الضرر أو الاسترداد أو الإتلاف)، والصنف والمستودع والدفعة أو الرقم التسلسلي والحالة قبل وبعد والكمية والسبب والمفتش والترحيل. المسودة لا تغيّر حالة المخزون حتى اعتماد الترحيل.
