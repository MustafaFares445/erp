# مرتجعات المخزون

## متى تستخدم هذه الصفحة؟

فحص كميات المرتجع وقرارات الحالة والأثر على المخزون.

## المهام الشائعة

- راجع قسم «مساران مختلفان» واتبع التعليمات المحددة فيه.
- راجع قسم «تنفيذ المرتجع» واتبع التعليمات المحددة فيه.
- راجع قسم «الحدود المالية» واتبع التعليمات المحددة فيه.

## مساران مختلفان

**مرتجع العميل** يستقبل البضاعة بعد تسليمها للعميل، ويستلزم ربطاً بالتسليم الأصلي وكميات مستلمة فعلياً ونتيجة فحص. أما **مرتجع المورد** فيعيد البضاعة من المستودع إلى المورد، مع التحقق من المستند الأصلي والكمية المتاحة. لا يجوز اعتبار كل مرتجع زيادة في الرصيد.

## تنفيذ المرتجع

1. افتح **المخزون ← العمليات ← المرتجعات** وراجع النوع والمصدر والحالة.
2. أنشئ المرتجع من مستند أصل مؤهل عند إتاحة الإجراء، وحدّد المستودع والطرف والمصدر.
3. في مرتجع العميل، سجّل الكمية المستلمة فعلياً وحدّد قرار الفحص: **قابل للبيع** أو **حجر** أو **تالف** أو **إرجاع للمورد**. قد يتطلب الترحيل إتمام الفحص أولاً. اختيار الإرجاع للمورد يحفظ البضاعة أولاً في الحجر حتى إتمام مرتجع المورد المنفصل.
4. في مرتجع المورد، راجع الكمية التي ستخرج وحالة المخزون المؤهلة والمستودع المعني.
5. اتبع مرحلتي الجاهزية والترحيل، ثم راجع الحركات الناتجة. يجب رفض زيادة الكميات عن الحدود المتاحة أو استخدام مصدر أو حالة غير صالحة.

## الحدود المالية

ترحيل مرتجع العميل لا ينشئ **إشعاراً دائناً** أو **استرداداً مالياً** تلقائياً. وترحيل مرتجع المورد لا يغيّر مستحقات المورد أو فواتيره آلياً. يجب معالجة الأثر المالي ضمن المبيعات والمدفوعات والمشتريات والمحاسبة بعد مطابقة الحركة المادية.

راجع [العمليات المخزنية](/ar/screens/inventory/inventory-operation) و[حركات المخزون](/ar/screens/inventory/stock-movement).

## صفحة View: ترحيل المرتجع والفصل المالي

يوضح قسم الحالة التشغيلية والإجراء التالي مرحلة مرتجع العميل أو المورد (Draft أو Ready أو Posted أو Cancelled). راجع التسليم أو الاستلام الأصلي والمستودع والبنود وحالة البضاعة والسبب والأثر المالي. ترحيل المرتجع عملية مخزنية؛ الإشعار الدائن أو الاسترداد المالي مسار مستقل.
