# طلبات عروض الأسعار من العملاء

## متى تستخدم هذه الصفحة؟

توضح هذه الصفحة المعلومات والخيارات المتاحة للمستخدم حسب حالته وصلاحياته.

## المهام الشائعة

- راجع قسم «مسار الطلب» واتبع التعليمات المحددة فيه.
- راجع قسم «قائمة الطلبات» واتبع التعليمات المحددة فيه.
- راجع قسم «إنشاء طلب» واتبع التعليمات المحددة فيه.

<IerpNavigationPath :items='["إدارة علاقات العملاء","العملاء","طلبات عروض الأسعار"]' />

تسجّل CRM طلب العميل للحصول على عرض سعر وتدير مراجعته قبل إحالته إلى المبيعات. طلب عرض السعر ليس عرضاً مسعّراً بحد ذاته، ولا يمثل طلبية بيع.

## مسار الطلب

1. افتح قائمة **طلبات عروض الأسعار** وابحث بالمرجع أو العميل أو الحالة. راجع المنتجات والكميات المطلوبة وملاحظات العميل.
2. في **إنشاء** اختر عميلاً مؤهلاً وعنوان التسليم عند الحاجة، ثم أضف المنتجات والكميات والملاحظات التوضيحية.
3. راجع الطلب وفق صلاحية العميل والمنتجات المطلوبة. الحالات هي **مقدّم** و**قيد المراجعة** و**تم إعداد عرض السعر** و**مرفوض** و**ملغى**.
4. استخدم إجراءات المراجعة أو التحويل المتاحة لصلاحيتك وللحالة الحالية. يستدعي التحويل المؤهل خدمة **عروض الأسعار التابعة للمبيعات** التي تحدد قواعد التسعير والعملة والموافقة اللاحقة.
5. افتح عرض السعر الناتج في **المبيعات** لمتابعة الإرسال والاعتماد وإنشاء الطلبية والتسليم لاحقاً. لا تعتبر طلب CRM بيعاً مكتملًا.
6. عند الرفض أو الإلغاء احتفظ بالطلب وسبب القرار وأدلة المراجعة بدلاً من حذف السجل التاريخي.
