# العملاء المحتملون

## متى تستخدم هذه الصفحة؟

توضح هذه الصفحة المعلومات والخيارات المتاحة للمستخدم حسب حالته وصلاحياته.

## المهام الشائعة

- راجع قسم «متابعة العميل وتأهيله» واتبع التعليمات المحددة فيه.
- راجع قسم «قائمة المتابعة» واتبع التعليمات المحددة فيه.
- راجع قسم «إنشاء عميل محتمل» واتبع التعليمات المحددة فيه.

<IerpNavigationPath :items='["إدارة علاقات العملاء", "مسار المبيعات", "العملاء المحتملون"]' />

تُستخدم هذه الشاشة لمتابعة العميل المحتمل من التواصل الأول حتى التأهيل والتحويل. تحتفظ وحدة CRM بسجل العميل والتفاعلات والأدلة، بينما يتم إنشاء حساب العميل عبر مسار التسجيل والاعتماد المحدد.

## متابعة العميل وتأهيله

1. افتح **CRM ← العملاء المحتملون** وابحث برقم العميل المحتمل أو الشركة أو اسم جهة الاتصال. استخدم فلتر **الخاملون منذ 14 يومًا أو أكثر** لمعرفة السجلات التي تحتاج متابعة.
2. راجع **المصدر** و**الحالة** والموظف المسؤول و**آخر تفاعل**. يمكن تجميع القائمة حسب الحالة أو المصدر أو المسؤول.
3. افتح **عرض** وراجع بيانات التواصل والتفاعلات وسجل انتقال الحالات قبل إضافة تفاعل جديد.
4. استخدم **تسجيل تفاعل** لتوثيق اتصال أو اجتماع. الانتقال من **جديد** إلى **تم التواصل** ثم **مؤهل** يخضع للأدلة وشروط الخدمة؛ لا يكفي تعديل نص الحالة.
5. استخدم **تعيين** لتحديد المسؤول، و**استبعاد** مع تسجيل السبب عند عدم الجدوى، و**تحويل** بعد استيفاء شروط التأهيل وبيانات العميل.

## إنشاء عميل محتمل

<IerpScreenshot id="crm-lead-create" title="نموذج العميل المحتمل" description="سجل الاسم وبيانات التواصل ومصدر العميل والمسؤول إن وجد." path="CRM ← العملاء المحتملون ← إنشاء" imageSrc="/images/ar/crm/crm-lead-create.png" />

أدخل الاسم الأول والأخير، واسم الشركة إن وجد، والبريد والهاتف والمصدر وتفاصيله. راجع الموظف المسؤول واللغة المفضلة قبل الحفظ. إنشاء السجل لا ينشئ عرض سعر أو حساب عميل تلقائيًا.

## عرض تفاصيل السجل

<IerpScreenshot id="crm-lead-view" title="تفاصيل العميل والأدلة" description="راجع التفاعلات وانتقالات المراحل والعميل الناتج عن التحويل إن وجد." path="CRM ← العملاء المحتملون ← عرض" />

توضح أقسام **التفاعلات** و**سجل مراحل العميل المحتمل** أسباب تقدم الحالة. وتُعرض كذلك بيانات العميل الناتج عن التحويل أو سبب الاستبعاد.

## التعديل عند السماح

<IerpScreenshot id="crm-lead-edit" title="تعديل بيانات العميل المحتمل" description="صحح بيانات العميل والمصدر طالما لم تصل الحالة إلى مرحلة نهائية." path="CRM ← العملاء المحتملون ← تعديل" />

الحالتان **تم التحويل** و**مستبعد** نهائيتان؛ لذلك يختفي إجراء التعديل المعتاد. لا تعدل قيم الحالة مباشرة لإعادة فتح السجل التاريخي.

## حدود المسؤولية وحل المشكلات

- التسلسل المعتاد هو **جديد ← تم التواصل ← مؤهل ← تم التحويل** بشرط توفر أدلة التفاعل؛ **مستبعد** حالة نهائية بديلة.
- تحويل العميل المحتمل يستدعي مسار تسجيل العميل في CRM. عروض الأسعار والطلبات تتبع وحدة المبيعات.
- إذا لم يظهر إجراء ما، تحقق من الصلاحية والحالة وأدلة التفاعل قبل افتراض وجود خطأ.
- البحث والعرض والتجميع لا تؤدي إلى حركة مخزون أو قيد محاسبي.
