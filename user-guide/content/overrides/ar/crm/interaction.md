# تفاعلات العملاء

## متى تستخدم هذه الصفحة؟

توضح هذه الصفحة المعلومات والخيارات المتاحة للمستخدم حسب حالته وصلاحياته.

## المهام الشائعة

- راجع قسم «تسجيل التفاعل ومراجعته» واتبع التعليمات المحددة فيه.
- راجع قسم «سجل التواصل» واتبع التعليمات المحددة فيه.
- راجع قسم «التدقيق وحدود العمل» واتبع التعليمات المحددة فيه.

يوثّق التفاعل اتصالاً أو اجتماعاً أو رسالة أو نشاطاً مرتبطاً بعميل محتمل أو مسجّل. ينبغي حفظ التاريخ والاتجاه والطرف والنتيجة الحقيقية؛ تدعم التفاعلات انتقالات CRM لكنها لا تحل محلها.

## تسجيل التفاعل ومراجعته

1. افتح **التفاعلات** وابحث عن العميل أو العميل المحتمل أو الملخص أو التاريخ. راجع **النوع** و**الاتجاه** و**وقت الحدوث** والطرف والموظف.
2. افتح العميل أو العميل المحتمل المرتبط إذا كان سياق التواصل غير واضح. قد يكون الطرف عميلاً محتملاً قبل التحويل، ثم يظهر ضمن سجل العميل المسجّل لاحقاً.
3. سجل النشاط من مسار العميل أو العميل المحتمل مع بيانات التواصل الفعلية والنتيجة والملاحظات. للعملاء المحتملين استخدم إجراء **تسجيل تفاعل**.
4. يمكن الجمع بين تسجيل التفاعل وترقية حالة العميل المحتمل **ضمن عملية ذرّية واحدة**. إذا كان الانتقال غير مسموح فلا ينبغي تسجيل التفاعل المحاول أو تغيير الحالة.
5. عند تحويل العميل المحتمل، يُحفظ سياق التفاعلات مع العميل الناتج. راجع السجل الزمني للعميل لمتابعة النشاط اللاحق.

## التدقيق وحدود العمل

التفاعل لا يمثل عرض سعر أو إرسال حملة أو قيداً مالياً. لا تسجل تفاعلاً وهمياً لتجاوز شرط تأهيل العميل. تحدد الصلاحية ومصدر البيانات السجلات المتاحة لكل مستخدم.
