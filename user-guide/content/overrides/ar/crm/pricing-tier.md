# شرائح التسعير

## متى تستخدم هذه الصفحة؟

توضح هذه الصفحة المعلومات والخيارات المتاحة للمستخدم حسب حالته وصلاحياته.

## المهام الشائعة

- راجع قسم «إدارة الشريحة» واتبع التعليمات المحددة فيه.
- راجع قسم «إدارة الشرائح» واتبع التعليمات المحددة فيه.

<IerpNavigationPath :items='["إدارة علاقات العملاء","التسعير","شرائح التسعير"]' />

تدير الشرائح خصومات العملاء وارتباطاتها بالمنتجات وفق الحد الأدنى للسعر. تطبق خدمات التسعير قيود الخصم والأهلية وفترة الصلاحية والموافقات.

## إدارة الشريحة

1. افتح **شرائح التسعير** وراجع النوع والخصم والعميل وحالة النشاط والتواريخ وعدد المنتجات والعملاء المرتبطين.
2. استخدم **إضافة شريحة** وحدد النوع **عام** أو **خاص بعميل** أو **مرتبط بمنتجات**؛ تختلف الحقول والقيود حسب النوع.
3. راجع حد الخصم المئوي الأعلى. عند الحاجة إلى موافقة وثق سبب الاستثناء بالإجراء المخول، ولا تقسّم الخصم لتجاوز الضابط.
4. استخدم **إسناد شريحة عامة** للعملاء المؤهلين أو **إدارة المنتجات** و**إدارة العملاء** للشرائح الخاصة بالمنتجات.
5. استخدم **معاينة السعر** لمراجعة السعر الأساسي والخصم والحد الأدنى. المعاينة ليست إذناً بالبيع دون الحد المعتمد.
6. لا تنفذ **التفعيل** أو **التعطيل** أو **التعديل** أو **الاستعادة** إلا بالصلاحية المسموحة، ولا تغير عروض المبيعات التاريخية بأثر رجعي.
