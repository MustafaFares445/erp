# طلبات الصيانة: التشخيص والضمان والتنفيذ والفوترة

<IerpPageSummary purpose="متابعة طلب صيانة مرتبط بتذكرة أو مستقل، وتحديد مسؤولية الضمان والعميل، وتوثيق العمل وربطه بالمستندات المالية المصرح بها." useWhen="عندما يحتاج العميل إلى إصلاح أو صيانة دورية أو تركيب أو معايرة أو زيارة خدمة." owner="الدعم والصيانة" />

## متى تستخدم هذه الصفحة؟

عندما يحتاج العميل إلى إصلاح أو صيانة دورية أو تركيب أو معايرة أو زيارة خدمة.

## المهام الشائعة

- راجع قسم «مسار العمل وصلاحيات الوحدات» واتبع التعليمات المحددة فيه.
- راجع قسم «قائمة الطلبات وإنشاء طلب» واتبع التعليمات المحددة فيه.
- راجع قسم «التشخيص واتخاذ قرار التغطية» واتبع التعليمات المحددة فيه.

## مسار العمل وصلاحيات الوحدات

المسار المعتاد هو **تذكرة ← طلب صيانة ← سجل خدمة**، ويمكن أيضاً إنشاء طلب مستقل. تحقق من العميل والتذكرة والجهاز والرقم التسلسلي وحيازة العميل للجهاز. قسم الدعم مسؤول عن التشخيص وقرار التغطية والإشراف على التنفيذ وفحص الجودة والإغلاق. المخزون مسؤول عن القطع والحيازة، والمبيعات عن عروض الأسعار والفواتير، والمدفوعات والمحاسبة عن التحصيل والقيود.

## قائمة الطلبات وإنشاء طلب

<IerpScreenshot id="support-maintenance-request-index" title="قائمة طلبات الصيانة" description="تابع الطلبات المفتوحة وبانتظار الموافقة وقيد التنفيذ وفحص الجودة والمغلقة، وحدد الإجراء المطلوب وحصة العميل." path="الدعم والصيانة ← طلبات الصيانة" />

ابحث بالعميل أو مرجع الطلب وحدد المرحلة. البحث والفرز لا يغيّران حالة الطلب ولا ينتج عنهما مبالغ مالية. انتبه خصوصاً إلى **بانتظار الموافقة**؛ فقد توجد تكاليف يتحملها العميل. الطلب المغلق ليس قابلاً للتعديل المباشر.

<IerpScreenshot id="support-maintenance-request-create" title="إنشاء طلب صيانة" description="اربط الطلب بالتذكرة عند وجودها، أو أدخل مبرر صيانة مستقل، مع التحقق من العميل والجهاز." path="طلبات الصيانة ← إنشاء" imageSrc="/images/ar/support/support-maintenance-request-create.png" />

إذا بدأ العمل من تذكرة، استخدم إجراء **إنشاء طلب صيانة** داخلها للحفاظ على المرجع. للطلب المستقل اختر العميل ووصف المشكلة، وحدد الجهاز المسلسل الذي يخصه فعلياً. لا تغيّر حيازة المعدات من شاشة الدعم.

## التشخيص واتخاذ قرار التغطية

<IerpScreenshot id="support-maintenance-request-view" title="تقييم طلب الصيانة" description="راجع التشخيص وأهلية الضمان وبنود التغطية وحصة العميل وإجراءات المرحلة قبل بدء الإصلاح." path="طلبات الصيانة ← عرض" />

1. انتقل إلى التشخيص حسب الحالة المسموحة. استخدم **تسجيل التشخيص** لتوثيق نتائج الفني والسبب الجذري وتصنيف العطل.
2. راجع بدء الضمان وتاريخ انتهائه وشروط التغطية والاستثناءات والرقم التسلسلي. كلام العميل وحده لا يثبت أهلية الضمان.
3. استخدم **تحديد التغطية**، وحدد لكل بند فئته ومبلغه و**نسبة التغطية**، مع سبب القرار الداخلي وشرح مستقل قابل للعرض للعميل.
4. راجع إجمالي المبلغ المغطى والمبلغ الذي يتحمله العميل. **التغطية الكاملة** و**الجزئية** و**المعالجة كاستثناء حسن نية** و**الخدمة المدفوعة** قرارات مختلفة.
5. إذا كان يلزم عرض سعر أو موافقة العميل، أبقِ الطلب في مرحلة انتظار مناسبة. لا تبدأ عملاً مدفوعاً غير موافق عليه.
6. أنشئ سجلات الخدمة وسجل عمل الفني والوقت والتكلفة الفعلية. استهلاك قطع الغيار يجب أن يستخدم خدمات المخزون المعتمدة.
7. اختبر جودة الإصلاح وأكمل أي إعادة عمل، ووثّق التركيب والمعايرة عند الحاجة قبل الإغلاق.

## الأثر المالي

| قرار التغطية | النتيجة |
| --- | --- |
| مغطى بالكامل | لا يتحمل العميل البنود المغطاة، لكن تكلفة العمل والمطالبة على المورد قد تبقى موجودتين. |
| مغطى جزئياً | يُحسب الجزء المغطى وحصة العميل لكل بند، ويجب شرح المبلغ والحصول على الموافقة المطلوبة. |
| حسن نية | إعفاء تجاري صريح؛ لا تسجّله خطأً على أنه ضمان ما زال سارياً. |
| مدفوع من العميل | تُنشأ وثيقة عرض سعر أو فاتورة عبر المبيعات حسب المسار المسموح، ثم تتم التسوية عبر الوحدات المالكة. |

**إجراءات عالية الأثر:** **إنشاء الفاتورة النهائية** و**تسوية الإصلاح المغطى** و**إعادة تصنيف فوترة الضمان** و**تصحيح معلومات الضمان** قد تؤثر في مبالغ العميل وسجل التدقيق وأهلية الخدمة. اقرأ نافذة التأكيد وسبب الإجراء المطلوب، ثم تحقق من النتيجة والمراجع المرتبطة. لا تختلق دفعة مالية من أجل إغلاق الطلب.

## سجلات الخدمة والتركيب والمعايرة

يتضمن سجل الخدمة مهام الفني ومرحلة التنفيذ والقطع المستخدمة والأدلة. التركيب مرتبط بجهاز مسلسل في حيازة العميل وشحنة وصلت فعلاً؛ يجب استكمال قائمة الفحص قبل اجتياز التشغيل الأولي، ولا يُسجل قبول العميل قبل نجاح التشغيل الأولي. يبدأ الضمان المرتبط بتلك المراحل عند تحقق شروطها الفعلية.

المعايرة نوع صيانة مستقل: وثّق القياسات والنتيجة والشهادة والفني وموعد الاستحقاق القادم. **لا تصدر شهادة نجاح لمعايرة فاشلة**. الزيارات الميدانية لها إجراءات مستقلة للتوزيع والوصول وتسجيل الحضور وتوقيع العميل؛ والجداول الوقائية تولّد حالات استحقاق لا تعني إنجاز الصيانة تلقائياً.

## التعديل والتصحيح والإغلاق

<IerpScreenshot id="support-maintenance-request-edit" title="تعديل تفاصيل الصيانة المسموح بها" description="يُمنع تعديل تفاصيل الطلب بعد الإغلاق أو الإلغاء أو الفوترة التجارية، مع بقاء انتقالات الحالة المخولة منفصلة." path="طلبات الصيانة ← تعديل" />

عندما يصبح الطلب مغلقاً أو ملغى أو تمت فوترته تجارياً، تكون تفاصيله مقفلة حتى لو كانت بعض انتقالات المرحلة متاحة لصلاحية أخرى. لا تتجاوز القفل بتغيير التواريخ أو المبالغ. استخدم إجراء التصحيح أو إعادة التصنيف الموثق أو طلباً جديداً عند الحاجة. الاستعادة محصورة بمدير النظام.

قبل الإغلاق تأكد من موافقة العميل عند اللزوم، ونتيجة فحص الجودة، واكتمال المهام والقطع والمعدات البديلة والمطالبة على المورد، وإحالة المتابعة المالية. **إغلاق الصيانة لا يثبت وحده تحصيل المبلغ أو ترحيل الإيراد**.
