## متى تستخدم هذه الصفحة؟

عندما يحتاج مدير الدعم إلى إشعار داخلي أو متابعة أو توجيه تلقائي متكرر.

## المهام الشائعة

- راجع قسم «التفعيل والسلامة» واتبع التعليمات المحددة فيه.
- راجع قسم «إنشاء قاعدة آمنة» واتبع التعليمات المحددة فيه.
- راجع قسم «التعديل ومراجعة النتائج» واتبع التعليمات المحددة فيه.

## التفعيل والسلامة

الأتمتة اختيارية ومعطلة افتراضياً حتى اعتماد تشغيلها. لا يمكن الوصول إلى شاشاتها عبر الروابط المباشرة عند التعطيل، وتبقى صلاحيات المستخدم مطبقة حتى بعد التفعيل. تُنفذ القواعد حسب أسبقيتها ويمكن إيقاف معالجة القواعد التالية. **غياب الشروط يجعل القاعدة تنطبق على كل حدث من النوع المختار**.

<IerpScreenshot id="support-support-automation-rule-index" title="قائمة قواعد الأتمتة" description="راجع الحدث والأسبقية والتفعيل وقرار إيقاف بقية القواعد قبل التعديل." path="الدعم المتقدم ← أتمتة الدعم" />

تشمل الأحداث إنشاء التذكرة وفرزها وإسنادها وتغيير الأولوية والحالة والرسائل، وخطر/خرق SLA، وانتظار العميل طويلاً وبعض أحداث الصيانة. تحقق من الحدث بدقة لتفادي إشعارات مكررة.

## إنشاء قاعدة آمنة

<IerpScreenshot id="support-support-automation-rule-create" title="إنشاء قاعدة أتمتة" description="اختر حدثاً وشروطاً وإجراءً مسموحاً، وأبقِ القاعدة غير فعالة حتى نجاح الاختبارات." path="أتمتة الدعم ← إنشاء" />

1. سمّ الهدف التجاري وحدد **الحدث** و**رقم الأسبقية**.
2. أضف الشروط بالحقول والعوامل المعتمدة. الشروط الفارغة تعني المطابقة الدائمة لهذا الحدث.
3. اختر الإجراء المسموح: إسناد فريق أو موظف مؤهل، تعديل الأولوية، نشر **ملاحظة داخلية**، إضافة متابع أو إنشاء مهمة متابعة.
4. فعّل **إيقاف معالجة القواعد التالية** فقط إن كانت القواعد الأقل أسبقية يجب ألا تعمل.
5. احتفظ بالقاعدة غير فعالة حتى التحقق منها في سيناريو مستقل، مع اختبار تكرار الحدث ومنع التكرار غير المقصود.

## التعديل ومراجعة النتائج

<IerpScreenshot id="support-support-automation-rule-edit" title="تعديل قاعدة أتمتة" description="راجع الحدث والشروط والإجراءات معاً قبل تغيير التفعيل أو الأسبقية." path="أتمتة الدعم ← تعديل" />

لا تسمح القواعد بتنفيذ PHP أو SQL أو أوامر النظام أو Webhooks عشوائية. الملاحظة الداخلية ليست رداً عاماً ولا تعالج متطلبات زمن الاستجابة الأول. لا يجوز أن يؤدي تكرار الحدث إلى مضاعفة المهام أو إعادة إسناد تذكرة منتهية. عند فشل القاعدة راجع سجل التنفيذ وقواعد الحالة بدلاً من تجاوزها.

الأتمتة لا تمنح صلاحية تسوية الدفع أو إصدار الفاتورة أو اتخاذ قرار ضمان أو تنفيذ إجراء غير قابل للتراجع خارج الإجراءات المصرح بها.
