# لوحة الدعم: أولويات العمل الحالية

## متى تستخدم هذه الصفحة؟

عند بدء دوام الدعم أو متابعة أعباء الفرق والفنيين.

## المهام الشائعة

- راجع قسم «ماذا تعرض اللوحة؟» واتبع التعليمات المحددة فيه.
- راجع قسم «خطوات بداية الدوام» واتبع التعليمات المحددة فيه.
- راجع قسم «المال والتصعيد» واتبع التعليمات المحددة فيه.

## ماذا تعرض اللوحة؟

<IerpScreenshot id="support-dashboard-overview" title="لوحة الدعم والصيانة" description="راجع عدد الحالات النشطة والتوجهات والمؤشرات المالية وقوائم التذاكر والصيانة التي تتطلب إجراء." path="الدعم والصيانة ← لوحة المعلومات" imageSrc="/images/ar/support/support-dashboard-overview.png" />

تعرض اللوحة مؤشرات التذاكر وتغيرها وقوائم المتابعة والصيانة القادمة والأعمال التي تحتاج اهتماماً. وعند تفعيل الميزات الاختيارية قد تظهر قوائم **المعايرة المستحقة أو المتأخرة أو الفاشلة** و**المعدات البديلة المتأخرة** و**الأجهزة لدى المورد**. ظهور المؤشر لا يمنح صلاحية لتعديل السجل المرتبط.

يمكن تصفية البيانات حسب الموظف والأولوية. قد تستخدم البطاقات والرسوم فترات زمنية أو نطاقات مختلفة؛ اقرأ عنوان المؤشر قبل مقارنة الأرقام. تغيير المرشحات لا يسند تذكرة ولا يكمل صيانة.

## خطوات بداية الدوام

1. راجع الحالات التي يمنعها الفرز أو الدفع أو معلومات العميل، وحدد الإجراء المسموح التالي.
2. ابدأ بالتذاكر المعرضة لخرق SLA أو المتأخرة، ثم راجع ساعة الاستجابة والحل داخل التذكرة.
3. افحص الزيارات وتوافر الفنيين، ولا تعتبر الزيارة منجزة لمجرد جدولة موعدها.
4. تابع الصيانة المنتظرة موافقة العميل أو قرار التغطية أو فحص الجودة وإعادة العمل. لا تبدأ إصلاحاً مدفوعاً جزئياً قبل عرض السعر المقبول حيث يلزم.
5. راجع الصيانة الوقائية والمعايرة والمعدات المتأخرة؛ نفّذ الإجراءات من الطلب المرتبط لا من رقم البطاقة في اللوحة.

## المال والتصعيد

أهلية ضمان الجهاز لا تعني تغطية هذا الإصلاح بالكامل. يقرر طلب الصيانة حصة العميل، وتملك المبيعات الفواتير والمدفوعات التحصيل والمحاسبة الترحيل. تلخيص التكلفة والإيراد في اللوحة ليس إثباتاً لتسديد دفعة.

عند اختلاف المؤشرات، افتح السجل أو التقرير المرتبط وراجع النطاق والفترة والحالة وسجل التدقيق بدلاً من تعديل التذكرة فقط لتغيير الرسم.
