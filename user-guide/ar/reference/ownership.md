# ملكية الوحدات

ينظم IERP العمل حسب ملكية كل حقيقة تجارية حتى لا تنشئ الوحدات مسارات مكررة.

| الحقيقة | الوحدة المالكة | المعنى |
| --- | --- | --- |
| المستند التجاري للعميل | المبيعات | عروض الأسعار والطلبات والفواتير والإشعارات الدائنة تتبع قواعد المبيعات. |
| الالتزام التجاري مع المورد | المشتريات | أوامر الشراء والتأكيد والتوريد مسؤولية المشتريات. |
| الحقيقة المادية للمخزون | المخزون | الكميات والدفعات والأرقام التسلسلية والعهدة والترحيل المادي مسؤولية المخزون. |
| الحقيقة الدفترية | المحاسبة | القيود والذمم والحقيقة المالية المرحلة مسؤولية المحاسبة. |
| حركة المال والتخصيص | المدفوعات | الاستلام والتخصيص وتسوية مزود الدفع تتم عبر مسارات الدفع. |
| العلاقة مع العميل | CRM | العملاء المحتملون والفرص والتفاعلات وسياق العميل مسؤولية CRM. |
| تخطيط وتنفيذ الموظف | الموظفون | الخطط والمهام والزيارات والفرص المراجعة والأداء مسؤولية الموظفين. |
| تنسيق الخدمة | الدعم والصيانة | التذاكر وSLA والضمان والصيانة مسؤولية الدعم. |
| التقارير | التقارير | تقرأ الحقائق ولا تصلحها بصمت. |

## لماذا هذا مهم؟

قد تبدأ شاشة في وحدة عملًا لوحدة أخرى لكنها لا تملك الأثر النهائي.

- المشتريات تجهز الاستلام لكن المخزون وحده يرحّل الكمية.
- الدعم قد يبدأ فوترة خدمة لكن المستند والتسوية يمران عبر المبيعات والمدفوعات والمحاسبة.
- المبيعات تخلق الطلب لكن تخصيص الدفعة/الرقم التسلسلي والتسليم المادي للمخزون.
- CRM تحول طلب المرتجع الموافق عليه إلى مرتجع مخزون، لكن الموافقة نفسها لا تحرك الكمية.
- التقرير يوضح الفرق بينما يتم التصحيح في الوحدة المالكة.
