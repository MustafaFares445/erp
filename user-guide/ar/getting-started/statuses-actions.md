# الحالات والإجراءات

توضح الحالة موقع السجل ضمن دورة حياته، أما الإجراء فهو الانتقال المضبوط الذي ينقله إلى المرحلة التالية أو الاستثناء.

لا يعتمد IERP على اللون وحده؛ يبقى نص الحالة ظاهرًا.

## الإجراء ليس تعديلًا عاديًا

الإرسال والموافقة والتأكيد والتحرير والترحيل والإكمال والحل والإغلاق والإلغاء والتصحيح كلها إجراءات يمكن أن تتحقق من الصلاحية والحالة والمصدر والمخزون والتتبع والعملة ووحدة القياس والتخصيص والفترة المالية والعمل الفرعي.

## نوافذ التأكيد

قبل تنفيذ إجراء حساس اقرأ السجل المتأثر والأثر اللاحق وقابلية العكس والسبب أو الإثبات المطلوب.

## التاريخ المرحّل

بعد عبور حد الترحيل يستخدم IERP التصحيح أو العكس أو المرتجع أو الإشعار الدائن أو الاسترداد أو القيد المقابل بدل التعديل الهدّام.

## الحالات الجزئية

الحالة الجزئية تعني أن هناك عملًا ما زال مفتوحًا مثل استلام جزئي أو تخصيص دفعة جزئي أو توفر جزئي أو تأكيد مورد جزئي.
