# البدء مع IERP

ينظم IERP لوحة التحكم ضمن **تسع وحدات عمل رئيسية**. كل وحدة تملك جزءًا محددًا من العملية، بينما تربط مسارات العمل بينها من البداية إلى النهاية.

## تسجيل الدخول

افتح لوحة الإدارة وأدخل بريدك الإلكتروني وكلمة المرور، ثم اختر تسجيل الدخول. اترك خيار تذكرني غير محدد على جهاز مشترك. بعد الدخول، استخدم مبدّل الوحدات لفتح المنطقة التي يسمح دورك باستخدامها.

## قاعدة الملكية

يفصل IERP المسؤوليات عمدًا:

- **المبيعات** تملك المستندات التجارية للعميل.
- **المشتريات** تملك الالتزامات التجارية مع المورد.
- **المخزون** يملك الحقيقة المادية للكميات والعهدة.
- **المحاسبة** تملك الحقيقة المالية والدفترية.
- **المدفوعات** تسجل حركة المال والتخصيص.
- **CRM** تملك سياق العلاقة مع العميل.
- **الموظفون** تملك التخطيط والزيارات والأداء.
- **الدعم والصيانة** تملك تنسيق الخدمة.
- **التقارير** تقرأ الحقائق ولا تصلحها مباشرة.

::: warning تحذير
لا تتجاوز مسار العمل بتغيير الحالة يدويًا أو تعديل كمية/قيمة مرحلة. استخدم الإجراء أو التصحيح أو العكس أو المرتجع أو الإشعار الدائن أو الاسترداد المخصص.
:::

## ماذا يغطي هذا الدليل؟

لكل شاشة فعلية قابلة للوصول من لوحة الإدارة مقال يشرح المسار والصفحات والحقول والجداول والفلاتر والإجراءات والتبويبات والأثر على العمل وأسباب الحظر. تظهر لقطات الشاشة بعد التحقق منها، وتبقى المراجع النصية للشاشات التي لم تُصوّر بعد.
