# الجداول والبحث والفلاتر

تبدأ أغلب شاشات العمل بقائمة جدول. فهم سلوك الجدول يجعل استخدام بقية الوحدات متشابهًا.

## البحث

استخدم بحث الجدول عندما تعرف رقمًا أو اسمًا تجاريًا، مثل رقم عرض السعر أو الطلب أو العميل أو المورد أو الصنف أو الرقم التسلسلي أو التذكرة. تختلف الحقول القابلة للبحث بحسب الصفحة.

## الفلاتر

تضيّق الفلاتر قائمة العمل دون تعديل السجلات. قد تكون حالة أو تاريخًا أو مستودعًا أو فريقًا أو مستخدمًا أو فلتر استثناء مثل المخزون المنخفض.

## طرق العرض المحفوظة

قد تعرض القوائم تبويبات جاهزة وStarred وطرق عرض محفوظة. يبقى شريط التبويبات في صف واحد قابل للتمرير بدل الالتفاف.

## الترتيب

يمكن ترتيب الأعمدة المدعومة بالنقر على العنوان. القيم الرقمية والتواريخ مصممة للقراءة السريعة.

## إجراءات الصف

تعمل على سجل واحد مثل العرض أو التعديل أو انتقال حالة أو تنزيل مستند. قد يختفي الإجراء إذا لم تسمح الحالة أو الصلاحية.

## الإجراءات الجماعية

لا تظهر إلا في الموارد التي تدعمها. راجع السجلات المحددة ورسالة التأكيد قبل التنفيذ.

## الصفحات

التنقل بين الصفحات يغير الجزء المرئي فقط ولا يغير الفلاتر أو حالة العمل.

## الحالة الفارغة

قد تعني عدم وجود سجلات، أو أن الفلاتر لا تعيد نتائج، أو أن نطاق صلاحيتك لا يسمح برؤية السجلات، أو أن إعدادًا يمنع إنشاء هذا النوع من العمل.
