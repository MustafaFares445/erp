# دفعات الموردين وتسوية الذمم الدائنة

<IerpPageSummary purpose="تسجيل دفعات الموردين وتخصيصها للفواتير المسموح بها مع حماية السجل المسدد." useWhen="سداد فاتورة مورد معتمدة أو جزء منها." owner="المحاسبة" />

## متى تستخدم هذه الصفحة؟

سداد فاتورة مورد معتمدة أو جزء منها.

## المهام الشائعة

- راجع قسم «تسوية الدفعات» واتبع التعليمات المحددة فيه.

## تسوية الدفعات

1. ابدأ من فاتورة مورد أو قائمة **دفعات الموردين** وحدد المورد وطريقة دفع نشطة والمبلغ والتاريخ؛ ينشأ السجل بوصفه **مسودة**.
2. نفّذ **دفع** على المسودة فقط واختر تخصيصات تخص المورد نفسه؛ تقبل التخصيصات الفواتير المعتمدة أو المدفوعة جزئيًا ذات رصيد مستحق فقط.
3. يسجل النظام قيد السداد وتخصيصاته ويحدث رصيد الفواتير المؤهلة. راجع حالة الفاتورة ومرجع الدفعة بعد الإجراء.
4. لا يمكن تعديل دفعة **مدفوعة** أو حذفها أو إعادتها إلى مسودة؛ اتبع مسار التصحيح المعتمد بدل تغيير بياناتها مباشرة.

**صفحة التعديل المعلّقة:** يلزم وجود دفعة مسودة حقيقية. لا تُفتح الدفعات المدفوعة لأغراض الصور.
