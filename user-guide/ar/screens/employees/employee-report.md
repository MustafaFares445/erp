# تقارير الموظفين

## متى تستخدم هذه الصفحة؟

توضح هذه الصفحة المعلومات والخيارات المتاحة للمستخدم حسب حالته وصلاحياته.

## المهام الشائعة

- راجع قسم «اختيار التقرير» واتبع التعليمات المحددة فيه.
- راجع قسم «مساحة التقارير» واتبع التعليمات المحددة فيه.
- راجع قسم «الصلاحيات وحدود التفسير» واتبع التعليمات المحددة فيه.

<IerpNavigationPath :items='["الموظفون","التقارير","تقارير الموظفين"]' />

تُستخدم التقارير لمراجعة تنفيذ المهام والزيارات والأداء والرواتب وفق الصلاحيات. تعتمد النتائج على السجلات الأصلية؛ ولا يغير تصديرها الحالة التشغيلية أو المالية.

## اختيار التقرير

1. افتح **تقارير الموظفين** وحدد الفئة المتاحة لدورك: **المهام والزيارات** أو **الأداء** أو **الرواتب**.
2. تشمل فئة العمل **إنجاز الخطط** و**المهام المتأخرة** و**الزيارات غير المنفذة** لتحديد فجوات التنفيذ.
3. تشمل فئة الأداء **الأداء حسب الموظف** و**الأداء حسب الشهر** لمقارنة النتائج المحسوبة المعتمدة.
4. تشمل فئة الرواتب **الراتب حسب الموظف** و**الراتب حسب الشهر**. تحقق من حالة الحساب قبل تفسير المبلغ؛ ولا يؤكد عرض التقرير الراتب.
5. طبّق فلاتر الجدول ثم استخدم **تصدير التقرير الحالي**. يتم وضع التصدير في قائمة التنفيذ وفق التقرير والفلاتر المختارة، وقد لا ينزل الملف مباشرة.
6. صحح اختلاف النتائج من الخطة أو المهمة أو الزيارة أو مراجعة الفرص أو حساب الأداء أو الراتب ثم أعد تشغيل التقرير.

## الصلاحيات وحدود التفسير

تظهر فئات التقارير بحسب صلاحيات المستخدم. اختفاء فئة لا يعني أن سجلاتها غير موجودة، وصلاحية عرض النتائج لا تعطي صلاحية تعديل الرواتب أو اعتماد المكافآت.
