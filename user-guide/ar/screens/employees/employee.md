# الموظفون

## متى تستخدم هذه الصفحة؟

توضح هذه الصفحة المعلومات والخيارات المتاحة للمستخدم حسب حالته وصلاحياته.

## المهام الشائعة

- راجع قسم «إدارة الموظفين» واتبع التعليمات المحددة فيه.
- راجع قسم «دليل الموظفين» واتبع التعليمات المحددة فيه.
- راجع قسم «إنشاء موظف» واتبع التعليمات المحددة فيه.

<IerpNavigationPath :items='["الموظفون","إدارة الكادر","الموظفون"]' />

تُستخدم الصفحة لإدارة ملفات الموظفين وصلاحيات الوصول ثم ربط المؤهلين بالخطط والمهام والزيارات والتقارير. حساب الموظف منفصل عن حساب العميل، ولا يجوز تغيير صلاحياته دون تفويض.

## إدارة الموظفين

1. ابحث برمز الموظف أو الاسم أو اسم المستخدم أو البريد أو الهاتف أو المسمى الوظيفي.
2. استخدم تبويبات **النشطون** و**غير النشطين** و**المعينون حديثًا** و**المؤرشفون**. تبويب المؤرشفين يعرض السجلات المؤرشفة بنطاق منفصل، وليس مجرد فلتر للنشاط.
3. أنشئ الموظف مع الهوية ووسائل التواصل والحساب المرتبط وفق قواعد التسجيل. تحقق من الأدوار والصلاحيات قبل التفعيل.
4. افتح **عرض** وراجع ملف الموظف والعمل المرتبط قبل تعديل الإسنادات.
5. استخدم **تعديل** عند السماح. لعمليات التفعيل أو التعطيل أو الأرشفة أو الاستعادة، استخدم مسار التحكم في وصول الموظف مع الاحتفاظ بسجل التدقيق.
6. راجع المهام والزيارات عند تعطيل موظف؛ لا تمحو تغييرات الوصول سجلات العمل المنجز أو الأداء أو الرواتب التاريخية.
