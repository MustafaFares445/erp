# تعريف الحقول المخصصة

<IerpNavigationPath :items='["الإدارة", "الإعدادات", "تعريف الحقول المخصصة"]' />

<IerpPageSummary purpose="عرّف حقولًا مخصصة مضبوطة توسع السجلات المدعومة دون إنشاء بنية بيانات حرة وغير محكومة." useWhen="عندما تحتاج للعمل على سجلات تعريف الحقول المخصصة أو متابعة دورة حياتها." owner="الإدارة" />

## نظرة عامة

عرّف حقولًا مخصصة مضبوطة توسع السجلات المدعومة دون إنشاء بنية بيانات حرة وغير محكومة.

يحتوي النظام على إدارة الوصول والقوالب والإعدادات المشتركة التي تستخدمها وحدات ERP.

## طريقة الوصول

استخدم مبدّل الوحدات واتبع المسار **الإدارة ← الإعدادات ← تعريف الحقول المخصصة**. تختلف الخيارات الظاهرة حسب صلاحيات المستخدم.

## الشاشات ضمن هذا القسم

| الشاشة | استخدامها |
| --- | --- |
| صفحة القائمة | القائمة الرئيسية لـ تعريف الحقول المخصصة. استخدمها للبحث والفلترة والترتيب وفتح السجلات وتنفيذ الإجراءات المتاحة حسب صلاحيتك. |

## متى تستخدم هذه الصفحة؟

استخدم **تعريف الحقول المخصصة** عندما يكون العمل تابعًا لمسؤولية الإدارة. تحافظ الصفحة على السجل في الوحدة المالكة للحقيقة التجارية بدل تكراره في وحدة أخرى.

## المهام الشائعة

- ابحث عن السجل باستخدام البحث وطرق العرض والفلاتر ثم افتحه من قائمة العمل.

## صفحة القائمة

<IerpScreenshot id="system-custom-field-definition-index" title="تعريف الحقول المخصصة — صفحة القائمة" description="القائمة الرئيسية لـ تعريف الحقول المخصصة. استخدمها للبحث والفلترة والترتيب وفتح السجلات وتنفيذ الإجراءات المتاحة حسب صلاحيتك." path="الإدارة ← الإعدادات ← تعريف الحقول المخصصة" imageSrc="/images/ar/system/system-custom-field-definition-index.png" />

القائمة الرئيسية لـ تعريف الحقول المخصصة. استخدمها للبحث والفلترة والترتيب وفتح السجلات وتنفيذ الإجراءات المتاحة حسب صلاحيتك.

هذه الشاشة قائمة عمل: استخدم البحث والفلاتر وطرق العرض لتحديد السجلات المطلوبة، ثم افتح السجل أو نفذ الإجراء المتاح حسب حالته.

### معلومات الجدول الأساسية

قد تعرض القائمة المعلومات التالية حسب الصلاحيات وإعداد الجدول:

- **Entity النوع**
- **الاسم**
- **الرمز**
- **Data النوع**
- **Is Required**
- **Is Active**
- **Values Count**
- **Sort الطلب**

### الفلاتر

استخدم الفلاتر لتضييق قائمة العمل دون تعديل السجلات:

- **Entity النوع** (SelectFilter)
- **Data النوع** (SelectFilter)
- **Is Active** (TernaryFilter)

## الحقول وسلوك النموذج

### الهوية والبيانات الرئيسية

| الحقل / المنطقة | نوع التحكم | طريقة الاستخدام |
| --- | --- | --- |
| Entity النوع | Select | يختار Entity النوع من الخيارات المهيأة والمسموح بها ضمن سياق السجل الحالي. |
| الاسم | TextInput | يسجل الاسم المقروء للمستخدم والذي يظهر في القوائم والاختيارات والتقارير. |
| الرمز | TextInput | يسجل المعرف التجاري الثابت المستخدم للبحث والمرجع وتمييز السجل. |
| Data النوع | Select | يختار Data النوع من الخيارات المهيأة والمسموح بها ضمن سياق السجل الحالي. |

### معلومات إضافية

| الحقل / المنطقة | نوع التحكم | طريقة الاستخدام |
| --- | --- | --- |
| Options | TagsInput | يسجل Options كبيانات منظمة يمكن أن تستخدمها الوحدة المالكة والتقارير المرتبطة. |
| الوصف | Textarea | يحفظ الوصف التجاري الظاهر مع السجل أو البند ويستخدم للسياق المفيد وليس بدل الحقول المنظمة. |
| Sort الطلب | TextInput | يتحكم بترتيب أو أولوية التطبيق عندما توجد عدة قواعد أو إدخالات ممكنة. |
| Is Required | Toggle | يفعّل أو يعطّل سلوك Is Required للمعالجة المستقبلية لهذا السجل. |
| Is Active | Toggle | يفعّل أو يعطّل سلوك Is Active للمعالجة المستقبلية لهذا السجل. |

قد تكون الحقول مطلوبة أو ظاهرة أو قابلة للتعديل بشكل شرطي حسب حالة السجل والاختيارات السابقة.

## الإجراءات والتحكم بدورة الحياة

توفر الصفحة الإجراءات حسب حالة السجل وصلاحية المستخدم. إذا لم يظهر إجراء متوقع فتحقق من الحالة والصلاحيات.

## الأثر على العمل

قد تؤثر إعدادات النظام على العمليات المستقبلية والصلاحيات والعرض المشترك، بينما يجب أن يبقى التاريخ المرحّل مستقرًا.

## أسباب شائعة لعدم توفر إجراء

- لا يملك المستخدم الصلاحية المطلوبة.
- حالة السجل الحالية لا تسمح بالإجراء.
- توجد موافقة أو مستند مصدر أو إعداد مطلوب غير مكتمل.
- السجل المرحّل أو المؤكد أصبح ثابتًا ويحتاج مسار تصحيح أو عكس.
- توجد أعمال غير مكتملة في وحدة مرتبطة مثل الاستلام أو الدفع أو الصيانة أو التنفيذ.
