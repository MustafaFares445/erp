# إشعارات التسليم

<IerpNavigationPath :items='["المبيعات", "التنفيذ والتسليم", "إشعارات التسليم"]' />

<IerpPageSummary purpose="راجع مستند التسليم التجاري وأدلة التسليم الناتجة عن تنفيذ طلب العميل." useWhen="عندما تحتاج للعمل على سجلات إشعارات التسليم أو متابعة دورة حياتها." owner="المبيعات" />

## نظرة عامة

راجع مستند التسليم التجاري وأدلة التسليم الناتجة عن تنفيذ طلب العميل.

تدير المبيعات الدورة التجارية للعميل من عرض السعر والطلب المؤكد حتى التنفيذ والفوترة والتحصيل والتصحيح بالائتمان.

## طريقة الوصول

استخدم مبدّل الوحدات واتبع المسار **المبيعات ← التنفيذ والتسليم ← إشعارات التسليم**. تختلف الخيارات الظاهرة حسب صلاحيات المستخدم.

## الشاشات ضمن هذا القسم

| الشاشة | استخدامها |
| --- | --- |
| صفحة القائمة | القائمة الرئيسية لـ إشعارات التسليم. استخدمها للبحث والفلترة والترتيب وفتح السجلات وتنفيذ الإجراءات المتاحة حسب صلاحيتك. |
| تفاصيل السجل | شاشة تفاصيل إشعارات التسليم. تجمع معلومات السجل والحالة والأعمال المرتبطة والسجل التاريخي والإجراءات المتاحة حسب السياق. |

## متى تستخدم هذه الصفحة؟

استخدم **إشعارات التسليم** عندما يكون العمل تابعًا لمسؤولية المبيعات. تحافظ الصفحة على السجل في الوحدة المالكة للحقيقة التجارية بدل تكراره في وحدة أخرى.

## المهام الشائعة

- ابحث عن السجل باستخدام البحث وطرق العرض والفلاتر ثم افتحه من قائمة العمل.
- راجع الحالة الحالية ومصادر السجل والإجماليات أو الأدلة والعمل المرتبط من شاشة التفاصيل.
- انقل السجل ضمن المسار باستخدام إجراءات مثل **إنشاء الفاتورة** بدل تغيير الحالة يدويًا.

## السلوك التشغيلي المتحقق منه

- Delivery Notes واجهة مبيعات للقراءة فوق عمليات تسليم يملكها Inventory. السجل هو InventoryOperation من النوع Delivery، لذلك تبقى الحقيقة المادية للمخزون في Inventory.
- تعرض القائمة رقم التسليم والعميل ومستودع المصدر والموعد والمرحلة وحالة الفوترة. فلتر Uninvoiced يركز على عمليات Done غير المرتبطة بفاتورة.
- تعرض التفاصيل المستودع والعميل والمرحلة وكميات البنود ووحداتها وحالة تجهيز المستودع والمستندات المرتبطة.
- Create Invoice يظهر فقط إذا كانت عملية التسليم Done وغير مفوترة ولدى المستخدم صلاحية إنشاء فاتورة، وينشئ Draft Invoice مرتبطة بعملية التسليم.
- Packing List والتنفيذ المادي للتسليم مسؤولية Inventory/Logistics ولا يجب تعديل كميات التسليم من واجهة المبيعات.

## صفحة القائمة

<IerpScreenshot id="sales-delivery-note-index" title="إشعارات التسليم — صفحة القائمة" description="القائمة الرئيسية لـ إشعارات التسليم. استخدمها للبحث والفلترة والترتيب وفتح السجلات وتنفيذ الإجراءات المتاحة حسب صلاحيتك." path="المبيعات ← التنفيذ والتسليم ← إشعارات التسليم" imageSrc="/images/ar/sales/sales-delivery-note-index.png" />

القائمة الرئيسية لـ إشعارات التسليم. استخدمها للبحث والفلترة والترتيب وفتح السجلات وتنفيذ الإجراءات المتاحة حسب صلاحيتك.

### طرق عرض التسليم

استخدم **Ready to dispatch** و**Delivered, not invoiced** و**Delivered** و**Cancelled** لفصل تقدم اللوجستيات عن متابعة الفوترة. يعني فلتر **Uninvoiced** أن عملية المخزون مكتملة ولا يوجد رابط فاتورة تسليم بعد.

يظهر **Create invoice** فقط لتسليم مكتمل وغير مفوتر عندما يملك المستخدم صلاحية إنشاء فاتورة.

هذه الشاشة قائمة عمل: استخدم البحث والفلاتر وطرق العرض لتحديد السجلات المطلوبة، ثم افتح السجل أو نفذ الإجراء المتاح حسب حالته.

### معلومات الجدول الأساسية

قد تعرض القائمة المعلومات التالية حسب الصلاحيات وإعداد الجدول:

- **Operation الرقم**
- **اسم شركة العميل**
- **Source المستودع الاسم**
- **Scheduled At**
- **Stage**
- **Invoiced**

### الفلاتر

استخدم الفلاتر لتضييق قائمة العمل دون تعديل السجلات:

- **Uninvoiced** (Filter)

## تفاصيل السجل

<IerpScreenshot id="sales-delivery-note-view" title="إشعارات التسليم — تفاصيل السجل" description="شاشة تفاصيل إشعارات التسليم. تجمع معلومات السجل والحالة والأعمال المرتبطة والسجل التاريخي والإجراءات المتاحة حسب السياق." path="المبيعات ← التنفيذ والتسليم ← إشعارات التسليم ← تفاصيل السجل" imageSrc="/images/ar/sales/sales-delivery-note-view.png" />

شاشة تفاصيل إشعارات التسليم. تجمع معلومات السجل والحالة والأعمال المرتبطة والسجل التاريخي والإجراءات المتاحة حسب السياق.

### ماذا تمثل شاشة التفاصيل؟

تقرأ الصفحة عملية التسليم المملوكة للمخزون: المرجع والحالة والعميل والمستودع المصدر والموعد والملاحظات والبنود وحالة تحضير المستودع. تعرض المستندات المرتبطة الاتصال بالطلب والشحنة والفاتورة.

يقوم **Generate Packing List** بإنتاج مستند تشغيلي. أما **Create invoice** عند توفره فينشئ فاتورة مسودة من التسليم المكتمل ثم ينتقل إليها.

### المعلومات الظاهرة في شاشة التفاصيل

قد تعرض شاشة التفاصيل معلومات مثل:

- **Operation الرقم**
- **Stage**
- **اسم شركة العميل**
- **Source المستودع الاسم**
- **Scheduled At**
- **الملاحظات**
- **البنود**
- **SKU متغير المنتج**
- **الكمية**
- **Is Picked**

## الإجراءات والتحكم بدورة الحياة

يتضمن التنفيذ الحالي تعريفات لإجراءات مثل:
- **إنشاء الفاتورة** — ينشئ السجل المرتبط عبر المسار المعتمد مع الحفاظ على السجل الحالي كمصدر.

قد تغير الإجراءات الحساسة المخزون أو المال أو الموافقات أو حالة العملية. اقرأ نافذة التأكيد قبل المتابعة.

## الأثر على العمل

قد تنشئ المبيعات أعمال تنفيذ وفوترة ودفع ومحاسبة لاحقة، لكن تغيير المخزون يتم فقط عبر إجراءات المخزون.

## أسباب شائعة لعدم توفر إجراء

- لا يملك المستخدم الصلاحية المطلوبة.
- حالة السجل الحالية لا تسمح بالإجراء.
- توجد موافقة أو مستند مصدر أو إعداد مطلوب غير مكتمل.
- السجل المرحّل أو المؤكد أصبح ثابتًا ويحتاج مسار تصحيح أو عكس.
- توجد أعمال غير مكتملة في وحدة مرتبطة مثل الاستلام أو الدفع أو الصيانة أو التنفيذ.
