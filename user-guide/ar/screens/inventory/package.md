# الطرود

<IerpPageSummary purpose="إدارة حاويات التعبئة الفعلية لتحضير الشحنات دون تغيير الأرصدة المخزنية مباشرة." useWhen="إنشاء طرد أو مراجعة نوعه ومستودعه أو تعديل سجل مسموح قبل الشحن." owner="المخزون" />

## متى تستخدم هذه الصفحة؟

إنشاء طرد أو مراجعة نوعه ومستودعه أو تعديل سجل مسموح قبل الشحن.

## المهام الشائعة

- راجع قسم «قبل البدء» واتبع التعليمات المحددة فيه.
- راجع قسم «البحث وتجهيز الطرد» واتبع التعليمات المحددة فيه.
- راجع قسم «متى تتغير الأرصدة؟» واتبع التعليمات المحددة فيه.

## قبل البدء

يجب تحديد **اسم الطرد** و**نوع طرد فعّال** و**مستودع فعّال**. نوع الطرد تعريف للتغليف، أما سجل الطرد فيمثل حاوية فعلية. تتحكم صلاحيات المستخدم في إظهار إجراءات الإنشاء والتعديل والحذف.

## البحث وتجهيز الطرد

1. افتح **المخزون ← الصادر ← الطرود** واستخدم البحث والفلاتر لمراجعة الاسم والنوع والمستودع والحالة.
2. اختر **إنشاء طرد**، أدخل اسماً واضحاً وحدد النوع والمستودع ثم احفظ. الإنشاء وحده لا يستلم مخزوناً ولا يحجزه ولا يرسله ولا ينقله.
3. افتح **عرض** للتحقق من بيانات الطرد المسجل ومستودعه قبل ربطه بعملية.
4. استخدم **تعديل** لتحديث البيانات المسموح بها. يصبح حقل المستودع مقفلاً عندما يكون الطرد مرتبطاً بعمل مخزني مسجل.

## متى تتغير الأرصدة؟

**ربط الطرد بعملية ليس حركة مخزنية.** تتغير الكميات فقط من خلال عمليات المخزون المؤكدة. يجب ألا يتسبب ربط الطرد بتغيير الموجود أو المحجوز أو المتاح. لا تحذف طرداً مرتبطاً ببنود أو حركات مخزنية، ولا تتجاوز حماية نقل الطرد المرتبط بين المستودعات بالتعديل المباشر.

## معالجة الحالات الفارغة

قد تعني القائمة الفارغة عدم وجود سجلات ضمن الفلاتر الحالية أو الصلاحيات. يجب تصوير صفحات العرض والتعديل باستخدام طرد محفوظ فعلياً ونوع ومستودع صالحين؛ الاستجابة الناجحة للرابط أو النموذج الفارغ لا تكفي لإثبات دورة العمل.
