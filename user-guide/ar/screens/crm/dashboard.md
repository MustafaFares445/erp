# لوحة معلومات علاقات العملاء

## متى تستخدم هذه الصفحة؟

توضح هذه الصفحة المعلومات والخيارات المتاحة للمستخدم حسب حالته وصلاحياته.

## المهام الشائعة

- راجع قسم «مراجعة المؤشرات» واتبع التعليمات المحددة فيه.
- راجع قسم «نظرة CRM العامة» واتبع التعليمات المحددة فيه.
- راجع قسم «حدود العمل» واتبع التعليمات المحددة فيه.

<IerpNavigationPath :items='["إدارة علاقات العملاء","نظرة عامة","لوحة المعلومات"]' />

تعرض اللوحة مؤشرات متابعة العملاء المحتملين ونمو العملاء ونتائج الحملات. هذه مؤشرات تشغيلية وليست بديلاً عن سجلات CRM أو مستندات المبيعات الأصلية.

## مراجعة المؤشرات

1. افتح لوحة CRM وحدد **الفترة الزمنية**. ويمكن استخدام فلتر **مصدر العميل المحتمل** لفحص النتائج المتعلقة بقناة اكتساب معينة.
2. راجع توزيع العملاء المحتملين بحسب الحالات. يبقى العميل المحوّل ضمن سجل التحويل التاريخي، ولا يعد فرصة مفتوحة جديدة.
3. قارن **نمو العملاء** مع **العملاء المحتملين الجدد حسب الحالة** خلال الفترة المختارة.
4. راجع قائمة **العملاء الخاملين منذ 14 يوماً أو أكثر**، ثم افتح سجل العميل المحتمل لتسجيل تفاعل المتابعة.
5. افحص نتائج إيصال الحملات والعملاء المحتملين المنسوبين إليها. تحقق من أدلة الردود في تفاصيل الحملة قبل نسبة أي مبيعات إليها.
6. نفّذ التصحيحات من صفحات **العملاء** أو **العملاء المحتملين** أو **التفاعلات** أو **الحملات**. لا يؤدي عرض المخططات أو تغيير الفلاتر إلى موافقة أو تحويل أو إرسال.

## حدود العمل

تتولى CRM بيانات العلاقات والتحويل، وتدير المبيعات العروض والطلبات، ويتولى المخزون المرتجعات الفعلية، وتتولى المحاسبة أرصدة القيود. لا تمثل المؤشرات المفلترة أرصدة مالية أو تعهداً بتوفر المخزون.
