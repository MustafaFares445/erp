# استثناءات الحد الأدنى للسعر

## متى تستخدم هذه الصفحة؟

توضح هذه الصفحة المعلومات والخيارات المتاحة للمستخدم حسب حالته وصلاحياته.

## المهام الشائعة

- راجع قسم «مراجعة الاستثناء» واتبع التعليمات المحددة فيه.
- راجع قسم «سجل الاستثناءات» واتبع التعليمات المحددة فيه.
- راجع قسم «عرض الاعتماد» واتبع التعليمات المحددة فيه.

<IerpNavigationPath :items='["إدارة علاقات العملاء","التسعير","استثناءات الحد الأدنى"]' />

يسجل الاستثناء موافقة صريحة على سعر أقل من الحد الأدنى المعتمد، مع سياق العميل والسعر المقترح والحد المحفوظ وسبب القرار وهوية المراجع والتاريخ.

## مراجعة الاستثناء

1. افتح سجل الاستثناءات وراجع رمز المنتج والشريحة والعميل والسعر المحاول والحد الأدنى.
2. افتح **عرض** وتحقق من سياق الاستثناء والموظف الذي اعتمده والتاريخ والسبب.
3. طابق الاستثناء مع المنتج والعميل المقصودين؛ ولا يعد تصريحاً بتجاوز قيود خصم أو مبيعات أخرى.
4. إذا كان السعر أو القرار خاطئاً، استخدم مسار التسعير والتصحيح المصرح، ولا تعدّل الدليل التاريخي مباشرة.
