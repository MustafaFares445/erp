# طلبات تغيير الأسعار

## متى تستخدم هذه الصفحة؟

توضح هذه الصفحة المعلومات والخيارات المتاحة للمستخدم حسب حالته وصلاحياته.

## المهام الشائعة

- راجع قسم «المراجعة» واتبع التعليمات المحددة فيه.
- راجع قسم «قائمة الطلبات» واتبع التعليمات المحددة فيه.
- راجع قسم «تفاصيل الطلب» واتبع التعليمات المحددة فيه.

<IerpNavigationPath :items='["إدارة علاقات العملاء","التسعير","طلبات تغيير الأسعار"]' />

تعرض الصفحة طلبات تعديل تكلفة متغير المنتج ونسبة الزيادة والسعر الأساسي والسعر الأدنى. تُدار مراجعة الأسعار عبر خدمات التسعير التابعة للمخزون، ولا تعد حقلاً لتغيير الأسعار دون اعتماد.

## المراجعة

1. افتح **طلبات تغيير الأسعار** وابحث برمز المنتج أو المتغير، وصفِّ حسب الحالة. راجع القيم ومقدم الطلب والتاريخ.
2. قارن **سعر التكلفة** و**نسبة الزيادة** و**السعر الأساسي** و**الحد الأدنى** مع المنتج والقيود التجارية.
3. حالات الطلب هي **معلق** و**معتمد** و**مرفوض**. يجوز للمراجع المخول اعتماد أو رفض أو تحديث الطلب المعلق فقط.
4. تطبق **الموافقة** التغيير المؤهل عبر خدمة تسعير المنتج؛ ويحفظ **الرفض** سبب القرار؛ ويعيد **التحديث** التحقق من القيم قبل تطبيقها.
5. السجل الذي خضع للمراجعة غير قابل للتعديل أو الحذف. يتأثر سعر العميل كذلك بالشريحة والأهلية واستثناء الحد الأدنى.
