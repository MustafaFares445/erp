# Quickstart: Complete Inventory Reports and Exports

1. Seed inventory permissions and grant `ReportView` plus the desired source permission.
2. Open Inventory Reports and select a permitted report tab.
3. Apply report filters and verify the table.
4. Grant `Export`, request the matching export, and run a queue worker.
5. Download the completed workbook through Inventory Exports.
6. Run focused tests, Pint, PHPStan, and the complete Composer gate.

Pricing-sensitive reports additionally require `PricingView`. Generated workbooks are stored privately.
