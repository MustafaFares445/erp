# CRM Workflows

---
status: canonical
owner: crm
last_verified: 2026-10-02
verified_against: CRM services
---

- Customer onboarding -> Pending review -> approve/request changes/reject/reactivate.
- Profile change -> Pending request -> approve/reject/cancel.
- Lead -> interactions/stage changes -> Qualified -> convert to Customer, or Disqualified.
- Customer quotation request -> Submitted -> Under Review -> Sales Quotation, or Rejected.
- Customer return request -> Submitted -> Under Review -> Approved -> Inventory Return, or Rejected.
- Campaign -> build recipients -> schedule/queue -> Notifications dispatch -> responses/attribution.
